# 豆包图片生成示例

通过平台图片 API（`https://model-api.skyengine.com.cn/v1`）调用豆包模型。请求前通过 `GET /v1/models` 确认当前环境开放的 Model ID。

## Seedream 5.5 同步生图

`doubao-seedream-5-5-261028` 支持文生图、单图编辑和最多 10 张参考图的融合编辑。普通生成一次返回一张图片，图层拆分会返回底图和多个图层。

<CodeGroup>

```bash cURL
curl --request POST 'https://model-api.skyengine.com.cn/v1/images/generations' \
  --header "Authorization: Bearer $TOKENOPS_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "doubao-seedream-5-5-261028",
    "prompt": "一张白底海报，上方清晰写着 HELLO 55，下方是一个红色圆形，简洁排版",
    "size": "2K",
    "output_format": "png",
    "response_format": "url",
    "watermark": false,
    "optimize_prompt_options": {"mode": "standard"}
  }'
```

```python Python
import os
import requests

response = requests.post(
    "https://model-api.skyengine.com.cn/v1/images/generations",
    headers={"Authorization": f"Bearer {os.environ['TOKENOPS_API_KEY']}"},
    json={
        "model": "doubao-seedream-5-5-261028",
        "prompt": "白色桌面上的红色陶瓷杯，产品摄影，横向构图",
        "size": "1K",
        "output_format": "jpeg",
        "response_format": "url",
        "watermark": False,
    },
    timeout=300,
)
response.raise_for_status()
result = response.json()
print(result["data"][0]["url"])
print(result["data"][0]["size"])
print(result["usage"]["generated_images"])
```

</CodeGroup>

`size` 的 `1K`、`1.5K`、`2K` 表示分辨率档位，具体宽高由模型结合提示词确定。例如 `2K` 可以返回 `2048x2048` 或 `1664x2496`。需要固定宽高时传入 `宽x高`，如 `2048x2048`。计费以响应中每张图片的实际宽高为准。

## Seedream 5.5 参数矩阵

| 参数 | 文生图／参考图编辑 | 图层拆分 | 取值与限制 |
| --- | --- | --- | --- |
| `model` | 必填 | 必填 | `doubao-seedream-5-5-261028` |
| `prompt` | 必填 | 可选 | 编辑时说明要修改和保留的内容；拆层时可描述希望拆出的对象 |
| `image` | 编辑时必填，1–10 张 | 必填，恰好 1 张 | 公网 URL 或 `data:image/...;base64,...`，支持字符串或字符串数组 |
| `size` | 默认 `2K`，支持 `1K`、`1.5K`、`2K` 或 `宽x高` | 默认 `auto`，支持 `auto`、`1K`、`1.5K`、`2K` | 生成自定义尺寸需满足总像素 921600–4624220、宽高比 1/16–16；拆层使用档位 |
| `output_format` | 默认 `png`，支持 `png`、`jpeg` | 控制底图格式，图层固定为 PNG | 透明输出需要 `png` |
| `response_format` | 支持 | 支持 | `url`（默认）或 `b64_json` |
| `background` | 默认 `auto`，支持 `auto`、`transparent`、`opaque` | 不支持，传入会报错 | `transparent` 输出 RGBA，参考图可以为普通 RGB 图片 |
| `layer_decomposition` | 省略或 `false` | `true` | 开启后将单图拆为底图与独立图层 |
| `layer_decomposition_options.max_images` | 拆层时生效 | 支持 | 2–100，默认 30，包含底图，实际返回数量可以更少 |
| `layer_decomposition_options.text_recognition` | 拆层时生效 | 支持 | 布尔值，默认 `false`，开启后返回规整文字图层的 OCR 结果 |
| `optimize_prompt_options.mode` | 支持 `standard` | 支持 `standard` | 提示词优化模式，5.5 仅支持 `standard` |
| `watermark` | 支持 | 支持 | 布尔值，建议显式指定 |
| `safety_identifier` | 支持 | 支持 | 终端用户的固定英文标识，最长 64 字符，可传用户 ID 的哈希值 |

平台当前单张输入图片按 **20MB** 上限配置。常用参考格式为 PNG、JPEG 和 WebP。`image` 数组保持输入顺序，提示词可用“图一”“图二”指代。

<Warning>
Seedream 5.5 使用同步请求。请省略 `stream` 或设为 `false`。该模型的普通生图只生成单张，`n` 省略或设为 `1`，不支持 `sequential_image_generation`、组图生成或 `tools.web_search`。拆层输出数量使用 `layer_decomposition_options.max_images` 控制。
</Warning>

## Seedream 5.5 图片编辑与多轮编辑

JSON 编辑请求使用 `/v1/images/edits`，也可以在 `/v1/images/generations` 中携带相同的 `image` 参数。将示例地址替换为可公开下载的图片 URL。

```bash cURL - 多参考图编辑
curl --request POST 'https://model-api.skyengine.com.cn/v1/images/edits' \
  --header "Authorization: Bearer $TOKENOPS_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "doubao-seedream-5-5-261028",
    "prompt": "保留图一杯子的形状和视角，将图二的圆形图案放到杯身上，保持白色桌面",
    "image": ["https://example.com/cup.png", "https://example.com/pattern.png"],
    "size": "1K",
    "output_format": "png",
    "response_format": "url",
    "watermark": false
  }'
```

本地图片可转为 Base64 data URI，使用同一个 JSON 接口。下例第二轮把第一轮输出作为参考图，继续修改同一张图片。

```python Python - Base64 与多轮编辑
import base64
import os
from pathlib import Path
import requests

headers = {"Authorization": f"Bearer {os.environ['TOKENOPS_API_KEY']}"}
image = "data:image/png;base64," + base64.b64encode(
    Path("reference.png").read_bytes()
).decode("ascii")
body = {
    "model": "doubao-seedream-5-5-261028",
    "image": [image],
    "prompt": "只把红色杯子改为绿色，保留蓝色贴纸、杯子形状与白色桌面",
    "size": "1K",
    "output_format": "png",
    "response_format": "url",
    "watermark": False,
}
response = requests.post(
    "https://model-api.skyengine.com.cn/v1/images/edits", headers=headers, json=body, timeout=300
)
response.raise_for_status()
first = response.json()

body["image"] = [first["data"][0]["url"]]
body["prompt"] = "在绿色杯身上增加黄色五角星，保留蓝色贴纸、杯子形状和拍摄角度"
response = requests.post(
    "https://model-api.skyengine.com.cn/v1/images/edits", headers=headers, json=body, timeout=300
)
response.raise_for_status()
print(response.json()["data"][0]["url"])
```

每轮请求都需要携带参考图片和本轮提示词。每一轮独立结算，本轮输入图数量包含再次提交的上一轮产物。

## Seedream 5.5 透明背景

文生图和参考图编辑都支持 `background: "transparent"`。编辑时输入普通 RGB 图片即可，提示词中说明要保留的主体与需要移除的背景。JPEG 无透明通道，`background: "transparent"` 与 `output_format: "jpeg"` 的组合会返回错误。

```bash cURL - 透明 PNG
curl --request POST 'https://model-api.skyengine.com.cn/v1/images/generations' \
  --header "Authorization: Bearer $TOKENOPS_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "doubao-seedream-5-5-261028",
    "prompt": "一个红色陶瓷杯，保留完整主体，透明背景，不要地面和阴影",
    "size": "1K",
    "background": "transparent",
    "output_format": "png",
    "response_format": "url",
    "watermark": false
  }'
```

将接口改为 `/v1/images/edits` 并加入 `image`，即可移除已有图片背景。`background: "auto"` 由模型结合提示词和文件格式决定是否输出透明通道，`opaque` 输出不透明图片。响应的 `data[].background` 表示实际结果，取值为 `transparent` 或 `opaque`。

## Seedream 5.5 图层拆分与富文本 OCR

拆层请求输入恰好一张图片，`layer_decomposition` 设为 `true`。示例最多返回 4 张图片，包含 1 张底图和最多 3 个图层。`max_images` 是上限，实际数量由图片内容与模型的拆分结果决定。

```bash cURL - 拆层与 OCR
curl --request POST 'https://model-api.skyengine.com.cn/v1/images/edits' \
  --header "Authorization: Bearer $TOKENOPS_API_KEY" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "doubao-seedream-5-5-261028",
    "image": ["https://example.com/poster.png"],
    "layer_decomposition": true,
    "layer_decomposition_options": {
      "max_images": 4,
      "text_recognition": true
    },
    "size": "auto",
    "output_format": "png",
    "response_format": "url",
    "watermark": false
  }'
```

<Info>
拆层时省略 `background`。底图使用 `output_format` 指定的格式，各独立图层始终为透明 PNG。默认 `size: "auto"` 依据输入图和各图层尺寸输出，底图、文字层和主体层的实际宽高可以不同。
</Info>

`data[]` 的 `z_index` 给出叠放顺序，底图为 0；图层的 `name`、`description` 描述内容，`bounding_box` 给出它在原图中的位置。开启 OCR 后，规整文字图层额外返回 `text_recognition`。非文字图层、艺术字和手写体等非规整文字可以没有该字段。

| 响应字段 | 含义 |
| --- | --- |
| `data[].url`／`b64_json` | 按 `response_format` 返回图片地址或 Base64 数据 |
| `data[].size` | 该张产物实际宽高，如 `1632x643` |
| `data[].output_format` | 该张产物文件格式 |
| `data[].background` | 实际透明度类型，`transparent` 或 `opaque` |
| `data[].z_index` | 底图及图层的叠放顺序 |
| `data[].bounding_box.absolute` | 图层在原图中的像素边界，顺序为 `[左, 上, 右, 下]` |
| `data[].bounding_box.normalized` | 同一边界的 0–1000 归一化坐标 |
| `data[].text_recognition.text` | 该文字图层的完整识别文本 |
| `data[].text_recognition.lines[]` | 逐行识别结果，包含行边界 `bounding_box` 和文字片段 `runs[]` |
| `lines[].runs[].text` | 该片段文字 |
| `lines[].runs[].style` | 近似视觉样式，包含 `similar_font_family`、`foreground_color`、`bold`、`italic`、`underline`、`strikethrough`、`shadow`、`translucent` |
| `usage.generated_images` | 实际生成图片总数，拆层时包含底图与所有返回图层 |
| `usage.total_tokens` | 模型返回的 Token 统计，本模型按图片张数和实际像素档位结算 |

例如文字层可返回以下 OCR 内容。样式字段表示识别到的近似视觉效果，`similar_font_family` 表示相似字体。

```json
{
  "text": "HELLO 55",
  "lines": [{
    "bounding_box": {
      "absolute": [221, 134, 700, 239],
      "normalized": [216, 131, 684, 233]
    },
    "runs": [{
      "text": "HELLO 55",
      "style": {
        "similar_font_family": "Rubik",
        "foreground_color": "#000000",
        "bold": false,
        "italic": false,
        "underline": false,
        "strikethrough": false,
        "shadow": false,
        "translucent": false
      }
    }]
  }]
}
```

## Seedream 5.5 计费

| 计费项 | CNY 单价 |
| --- | --- |
| 输入图片 | 每张 ¥0.05，从第一张起计费 |
| 输出图片，总像素 ≤ 2610000 | 每张 ¥0.13 |
| 输出图片，总像素 > 2610000 | 每张 ¥0.23 |

生图、编辑、透明图和拆层按这套价格结算。输出总像素使用每张返回图片的实际 `宽 × 高` 计算，拆层的底图与各图层分别分档。开启 OCR 沿用拆层计费，当前没有单独的 OCR 收费项。

例如，输入 1 张海报，实际返回 1 张底图与 2 个图层，三张输出都不超过 2610000 像素，费用为 `1 × 0.05 + 3 × 0.13 = ¥0.44`。即使 `max_images` 设为 4，也按实际返回的 3 张结算。若其中一张超过低档像素上限，则该张按 ¥0.23 结算。

平台将输入及各输出档位的费用汇总到同一个订单，账单 `applied_price_items` 中可查看 `img.input`、`img.output_r1`、`img.output_r2` 的实际数量与费用。普通生图返回单张图片，拆层返回多张，均可将 `usage.generated_images`、`data` 长度和最终账单输出数量对照核验。

## Seedream 4.0 基础与组图示例

<CodeGroup>

```bash cURL
curl -X POST "https://model-api.skyengine.com.cn/v1/images/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <API-KEY>" \
  -d '{
    "prompt": "一只可爱的小猫在花园里玩耍，阳光明媚，油画风格",
    "model": "doubao-seedream-4.0-250828",
    "size": "1024x1024",
    "response_format": "url",
    "watermark": true
  }'
```

```python Python
import requests
import json
import base64
from PIL import Image
from io import BytesIO

API_KEY = "<API-KEY>"
BASE_URL = "https://model-api.skyengine.com.cn/v1"

def generate_image_doubao(prompt, model="doubao-seedream-4.0-250828", size="1024x1024",
                         watermark=True, response_format="url"):
    """
    使用豆包API生成图片
    
    Args:
        prompt: 图片描述文本
        model: 模型名称，默认doubao-seedream-4.0-250828
        size: 图片尺寸
        watermark: 是否添加水印
        response_format: 返回格式，url或b64_json
    """
    url = f"{BASE_URL}/images/generations"
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}"
    }
    
    data = {
        "prompt": prompt,
        "model": model,
        "size": size,
        "response_format": response_format,
        "watermark": watermark
    }
    
    response = requests.post(url, headers=headers, json=data)
    
    if response.status_code == 200:
        result = response.json()
        images = []
        
        # 显示响应信息
        if 'created' in result:
            print(f"生成时间: {result['created']}")
        if 'usage' in result:
            usage = result['usage']
            print(f"Token使用: 总计={usage.get('total_tokens')}, 输出={usage.get('output_tokens')}")
        
        for i, img_data in enumerate(result['data']):
            if response_format == "b64_json" and 'b64_json' in img_data:
                # 处理base64格式
                image_data = base64.b64decode(img_data['b64_json'])
                image = Image.open(BytesIO(image_data))
                filename = f"doubao_generated_{i+1}.png"
                image.save(filename)
                images.append(filename)
                print(f"图片已保存: {filename}")
            elif 'url' in img_data:
                # 处理URL格式（24小时内有效）
                print(f"图片URL: {img_data['url']}")
                images.append(img_data['url'])
                
            # 显示修订后的提示词（如果有）
            if 'revised_prompt' in img_data:
                print(f"修订后的提示词: {img_data['revised_prompt']}")
        
        return images
    else:
        print(f"错误: {response.status_code} - {response.text}")
        return None

# 基础使用示例
if __name__ == "__main__":
    prompt = "一只可爱的小猫在花园里玩耍，阳光明媚，油画风格"
    images = generate_image_doubao(prompt)
    
    if images:
        print(f"成功生成 {len(images)} 张图片")
```

```python Python - 流式生成
import requests
import json
import base64
from PIL import Image
from io import BytesIO

API_KEY = "<API-KEY>"
BASE_URL = "https://model-api.skyengine.com.cn/v1"

def generate_image_doubao_stream(prompt, model="doubao-seedream-4.0-250828", size="1024x1024"):
    """
    使用豆包API流式生成图片
    """
    url = f"{BASE_URL}/images/generations"
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}"
    }
    
    data = {
        "prompt": prompt,
        "model": model,
        "size": size,
        "stream": True,
        "response_format": "url",
        "watermark": True
    }
    
    response = requests.post(url, headers=headers, json=data, stream=True)
    
    if response.status_code == 200:
        images = []
        for line in response.iter_lines():
            if line:
                line = line.decode('utf-8')
                if line.startswith('data:'):
                    try:
                        json_data = line[5:]  # 移除'data:'前缀
                        if json_data.strip() == '[DONE]':
                            break
                        
                        event = json.loads(json_data)
                        
                        # 处理不同类型的事件
                        if event.get('type') == 'image_generation.partial_succeeded':
                            print(f"图片 {event.get('image_index', 0)} 生成中...")
                        elif event.get('type') == 'image_generation.completed':
                            print("图片生成完成")
                            if 'url' in event:
                                images.append(event['url'])
                                print(f"图片URL: {event['url']}")
                        elif event.get('type') == 'error':
                            print(f"生成错误: {event.get('error', {}).get('message', '未知错误')}")
                            
                    except json.JSONDecodeError as e:
                        print(f"解析JSON失败: {e}")
                        continue
        
        return images
    else:
        print(f"错误: {response.status_code} - {response.text}")
        return None

# 流式生成示例
if __name__ == "__main__":
    prompt = "科幻城市夜景，霓虹灯闪烁，赛博朋克风格"
    images = generate_image_doubao_stream(prompt)
    
    if images:
        print(f"流式生成完成，共 {len(images)} 张图片")
```

```python Python - 高级功能
import requests
import json

API_KEY = "<API-KEY>"
BASE_URL = "https://model-api.skyengine.com.cn/v1"

def generate_image_doubao_advanced(prompt, **kwargs):
    """
    豆包图片生成高级功能示例
    
    支持的高级参数：
    - sequential_image_generation: 组图功能控制
    - sequential_image_generation_options: 组图功能配置
    - optimize_prompt_options: 提示词优化配置
    - image: 基于现有图片生成（图片编辑）
    """
    url = f"{BASE_URL}/images/generations"
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}"
    }
    
    # 基础参数
    data = {
        "prompt": prompt,
        "model": kwargs.get("model", "doubao-seedream-4.0-250828"),
        "n": kwargs.get("n", 1),
        "size": kwargs.get("size", "1024x1024"),
        "response_format": kwargs.get("response_format", "url"),
        "watermark": kwargs.get("watermark", True)
    }
    
    # 高级功能参数
    if kwargs.get("enable_sequential"):
        data["sequential_image_generation"] = "auto"
        data["sequential_image_generation_options"] = {
            "max_images": kwargs.get("max_images", 4)
        }
    
    if kwargs.get("optimize_prompt"):
        data["optimize_prompt_options"] = {
            "enable": True
        }
    
    if kwargs.get("base_image"):
        data["image"] = kwargs["base_image"]  # URL或base64编码
    
    response = requests.post(url, headers=headers, json=data)
    
    if response.status_code == 200:
        result = response.json()
        print(f"生成时间: {result.get('created')}")
        
        if result.get('usage'):
            usage = result['usage']
            print(f"Token使用: 总计={usage.get('total_tokens')}, 输出={usage.get('output_tokens')}")
        
        return result['data']
    else:
        print(f"错误: {response.status_code} - {response.text}")
        return None

# 高级功能使用示例
if __name__ == "__main__":
    # 1. 组图生成

        n=3,
        enable_sequential=True,
        max_images=3,
        optimize_prompt=True
    )
    
    # 2. 基于现有图片的编辑
    print("\n=== 图片编辑示例 ===")
    base_image_url = "https://example.com/base_image.jpg"
    edited_images = generate_image_doubao_advanced(
        prompt="将图片改为水彩画风格",
        base_image=base_image_url
    )
```

## 支持的参数

### 基础参数
- **prompt**: 图片描述文本（必需），建议不超过 300 汉字或 600 英文单词
- **model**: 模型名称
- **n**: 生成图片数量。5.5、5.0 Pro / Flash 的普通生成仅支持单图；5.5 拆层数量由 `layer_decomposition_options.max_images` 控制
- **size**: 图片尺寸，分辨率等级（如 `"1K"`、`"2K"`、`"3K"`）或精确像素值（如 `"2048x2048"`）。5.5、5.0 Pro / Flash 支持 `1K`、`1.5K`、`2K`
- **response_format**: 返回格式（`url` 或 `b64_json`）
- **output_format**: 输出图片格式（`png` 或 `jpeg`），5.5、5.0 Pro / Flash / lite 支持 png
- **seed**: 随机数种子，-1 表示随机

### 画质控制参数
- **watermark**: 是否添加水印，默认 `true`

### 高级功能参数
- **stream**: 是否启用流式输出，默认 `false`
- **tools**: 工具列表，如 `[{"type": "web_search"}]` 开启联网搜索（用于 5.0 lite）
- **sequential_image_generation**: 组图功能控制（`auto` 或 `disabled`）
- **sequential_image_generation_options**: 组图功能配置
  - **max_images**: 最大图片数量
- **Seedream 5.0 Pro 注意事项**: `doubao-seedream-5.0-pro` 不支持 `sequential_image_generation` / `sequential_image_generation_options`，调用 Pro 时请不要传这两个字段
- **optimize_prompt_options**: 提示词优化配置
  - **mode**: 优化模式（`standard`）
- **image**: 参考图片，支持 URL 或 Base64 data URI。5.5、5.0 Pro / Flash 最多 10 张，lite / 4.0 / 4.5 最多 14 张；拆层恰好输入 1 张

## 图片到图片生成示例

豆包还支持基于现有图片生成新图片的功能，通过 `image` 参数提供参考图片URL：

```python Python - 图片到图片
import requests

API_KEY = "<API-KEY>"
BASE_URL = "https://model-api.skyengine.com.cn/v1"

def generate_image_from_image(prompt, base_image_url, model="doubao-seedream-4.0-250828", size="1024x1024"):
    """
    基于现有图片生成新图片
    
    Args:
        prompt: 生成描述
        base_image_url: 参考图片的URL
        model: 模型名称
        size: 输出图片尺寸
    """
    url = f"{BASE_URL}/images/generations"
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {API_KEY}"
    }
    
    data = {
        "prompt": prompt,
        "image": base_image_url,
        "model": model,
        "size": size,
        "response_format": "url",
        "watermark": True
    }
    
    response = requests.post(url, headers=headers, json=data)
    
    if response.status_code == 200:
        result = response.json()
        print(f"生成时间: {result.get('created')}")
        
        if result.get('usage'):
            usage = result['usage']
            print(f"Token使用: 总计={usage.get('total_tokens')}, 输出={usage.get('output_tokens')}")
        
        for i, img_data in enumerate(result['data']):
            if 'url' in img_data:
                print(f"生成的图片URL: {img_data['url']}")
                return img_data['url']
    else:
        print(f"错误: {response.status_code} - {response.text}")
        return None

# 使用示例
if __name__ == "__main__":
    base_image = "https://ark-project.tos-cn-beijing.volces.com/doc_image/seedream4_imageToimage.png"
    new_image = generate_image_from_image(
        prompt="生成狗狗趴在草地上的近景画面",
        base_image_url=base_image
    )
```
