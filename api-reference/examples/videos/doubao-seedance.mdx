# 豆包 Seedance 视频生成

Seedance 2.5 支持文生视频、首帧/首尾帧图生视频，以及图片、视频和音频的多模态参考。任务采用异步模式：先创建任务，再使用任务 ID 查询结果。

## 模型与规格

| 模型 ID | 输出时长 | 输出分辨率 | 帧率 |
| --- | --- | --- | --- |
| `doubao-seedance-2.5` | 4～30 秒 | 480p、720p、1080p | 24 fps |
| `doubao-seedance-2-0-260128` | 4～15 秒 | 480p、720p、1080p、4K | 24 fps |
| `doubao-seedance-2-0-fast-260128` | 4～15 秒 | 480p、720p | 24 fps |

Seedance 2.5 默认使用 720p。建议显式传入 `duration` 和 `resolution`，以便调用结果与费用预估保持一致。1080p 与 480p/720p 使用不同计费档位，请以 `GET /v1/models` 返回的当前价格规则为准。

能力范围依据[火山引擎 Seedance 2.5 官方文档](https://docs.volcengine.com/docs/82379/2607688?lang=zh)整理；厂商能力和价格可能调整，调用前请同时核对模型列表。

## 创建任务

所有模型参数均位于请求顶层。下面的请求生成一段 5 秒、720p、带声音的视频，并要求在查询结果中返回尾帧图片。

```bash cURL
curl --request POST \
  --url https://model-api.skyengine.com.cn/v1/videos \
  --header 'Authorization: Bearer <API-KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "doubao-seedance-2.5",
    "content": [
      {
        "type": "text",
        "text": "电影感航拍：清晨薄雾中的山谷，镜头平稳向前推进，远处阳光穿过云层"
      }
    ],
    "duration": 5,
    "resolution": "720p",
    "output_format": "mov",
    "ratio": "16:9",
    "generate_audio": true,
    "return_last_frame": true,
    "watermark": false
  }'
```

创建成功后返回任务 ID：

```json
{ "id": "cgt-2026******-****" }
```

### 首尾帧图生视频

使用 `role` 区分首帧和尾帧。图片 URL 必须能够被模型服务访问。

```json
{
  "model": "doubao-seedance-2.5",
  "content": [
    { "type": "text", "text": "从白天自然过渡到黄昏，保持主体一致，镜头缓慢拉远" },
    {
      "type": "image_url",
      "image_url": { "url": "https://example.com/first-frame.png" },
      "role": "first_frame"
    },
    {
      "type": "image_url",
      "image_url": { "url": "https://example.com/last-frame.png" },
      "role": "last_frame"
    }
  ],
  "duration": 6,
  "resolution": "720p",
  "generate_audio": true,
  "return_last_frame": true
}
```

### 多模态参考

参考素材使用 `reference_image`、`reference_video` 和 `reference_audio` 角色。提示词可用“图片 1”“视频 1”“音频 1”等自然语言指代对应素材。

```json
{
  "model": "doubao-seedance-2.5",
  "content": [
    { "type": "text", "text": "保持图片 1 中人物外观，参考视频 1 的运镜，并按照音频 1 的节奏剪辑" },
    {
      "type": "image_url",
      "image_url": { "url": "https://example.com/character.png" },
      "role": "reference_image"
    },
    {
      "type": "video_url",
      "video_url": { "url": "https://example.com/camera-motion.mp4" },
      "role": "reference_video"
    },
    {
      "type": "audio_url",
      "audio_url": { "url": "https://example.com/rhythm.mp3" },
      "role": "reference_audio"
    }
  ],
  "duration": 10,
  "resolution": "720p",
  "ratio": "16:9",
  "generate_audio": true
}
```

Seedance 2.5 多模态参考最多支持 30 张图片；参考视频和参考音频各最多 10 个，单类素材总时长不超过 30 秒。具体素材格式、大小及组合限制以厂商最新规则为准。

## 查询任务

```bash cURL
curl --request GET \
  --url https://model-api.skyengine.com.cn/v1/videos/<TASK-ID> \
  --header 'Authorization: Bearer <API-KEY>'
```

统一接口状态包括 `in_queue`、`in_progress`、`completed`、`failed` 和 `expired`。成功响应示例：

```json
{
  "id": "cgt-2026******-****",
  "model": "doubao-seedance-2.5",
  "status": "completed",
  "content": {
    "video_url": "https://example.com/generated-video.mov",
    "last_frame_url": "https://example.com/generated-last-frame.png"
  },
  "output_format": "mov",
  "resolution": "720p",
  "ratio": "16:9",
  "duration": 5,
  "framespersecond": 24,
  "generate_audio": true,
  "usage": { "completion_tokens": 108900, "total_tokens": 108900 }
}
```

`expired` 表示任务超过执行有效期，不能再继续处理，应重新创建任务。

## 常用参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | string | 是 | 模型 ID，例如 `doubao-seedance-2.5` |
| `content` | array | 是 | 文本及图片、视频、音频输入 |
| `duration` | integer | 否 | Seedance 2.5 为 4～30 秒，或 `-1` 智能选择；默认 `-1`，视频编辑必须使用 `-1` |
| `output_format` | string | 否 | Seedance 2.5 支持 `mp4`、`mov`，默认 `mp4`；MOV 适用于专业后期，转存与下载保留实际格式 |
| `omni_reference_task_type` | string | 否 | Seedance 2.5 全模态任务类型：`auto`、`reference`、`edit`、`extend`；编辑与延长需参考视频及 `ratio: adaptive` |
| `execution_expires_after` | integer | 否 | 任务执行有效期，单位秒；范围 3600～259200，官方默认 172800 |
| `priority` | integer | 否 | 同一推理接入点的排队优先级，范围 0～9，官方默认 0 |
| `safety_identifier` | string | 否 | 固定且唯一的终端用户标识，最多 64 个字符，推荐使用哈希值 |
| `callback_url` | string | 否 | 厂商任务状态回调地址，通知体采用厂商原生查询格式 |
| `resolution` | string | 否 | 支持 `480p`、`720p`、`1080p`，默认 `720p`；不同分辨率的计费档位不同 |
| `ratio` | string | 否 | 文生视频支持 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9`、`adaptive`；首帧/首尾帧、编辑及延长仅支持 `adaptive`，输出比例跟随原素材 |
| `generate_audio` | boolean | 否 | 是否生成与画面同步的音频；建议显式传入，避免依赖厂商默认值 |
| `return_last_frame` | boolean | 否 | 是否在成功结果中返回尾帧图片 |
| `camera_fixed` | boolean | 否 | 官方字段，兼容旧拼写 `camerafixed`；仅适用于支持此能力的旧模型，Seedance 2.5 不支持 |
| `service_tier` | string | 否 | 厂商服务等级；Seedance 2.5 不支持 `flex`，建议省略 |
| `draft` | boolean | 否 | Seedance 1.5 pro 样片模式；正式生成可通过 `content[].draft_task.id` 引用样片，Seedance 2.5 不支持 |
| `watermark` | boolean | 否 | 是否添加水印 |
| `seed` | integer | 否 | 仅支持该能力的旧模型；范围 `[-1, 2147483647]`，显式 `0` 保留；Seedance 2.5 不支持 |

<Warning>
参数会按调用方显式传入的值交由厂商校验，省略时使用厂商默认值。`seed`、`camera_fixed`、`draft` 和 `service_tier: flex` 属于旧模型能力，不能用于 Seedance 2.5。创建参数依据[官方创建接口文档](https://docs.volcengine.com/docs/82379/1520757)整理。
</Warning>

<Note>
查询接口返回的下载 URL 可能有有效期。任务成功后请及时下载并保存视频；应用侧轮询时建议采用递增间隔，避免高频请求。
</Note>
