# JEV 决策评估示例

以下示例通过平台的 `/v1/systemone` 接口调用 `jev-1.13.0`，根据同一份客服工单，同时判断处理团队、紧急程度和退款意图。模型返回结构化决策与概率。

## 快速开始

替换 `<API-KEY>` 为你的平台 API 密钥即可调用。Python 示例需要安装 `requests`，JavaScript/Node.js 示例需要安装 `axios`；Java 示例使用 JDK 17 或更高版本，PHP 示例需要启用 cURL 扩展并使用 PHP 7.3 或更高版本。

## 读取判断结果

| 问题类型 | 本例问题 | 读取字段 | 含义 |
| --- | --- | --- | --- |
| Choice | 由哪个团队处理 | `answers.department.choice` | 选中的选项名称，例如 `billing` |
| Score | 工单有多紧急 | `answers.urgency.score` | 有序等级的加权评分，本例范围为 0～2，可为小数 |
| Noul | 是否要求退款 | `answers.refund.noul` | 判断为“是”的概率，范围为 0～1 |

Choice 和 Score 还返回 `probabilities` 与 `confidence`；Score 的 `legend` 对应从 0 开始的等级描述。`noul=0.99` 表示“是”的概率为 0.99。业务决策阈值需要根据实际场景验证。

## 重要参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `model` | string | 平台模型名，本例为 `jev-1.13.0` |
| `state` | string / object / array | 所有问题共享的文本上下文，可用字符串、JSON 对象或文本数组 |
| `questions` | object | 问题 ID 到问题定义的映射；响应通过相同 ID 返回答案 |
| `instructions` | string / object / array | 单题描述；本例使用字符串 |
| `criteria` | object / array | Choice 为选项映射，最多 255 项；Score 为 2～10 个由低到高的等级；Noul 可省略 |
| `include_cost` | boolean | 平台扩展参数，设为 `true` 时在 `usage` 中返回费用和币种；不需要费用时省略 |

单次请求的 `state` 与所有问题合计最多 64K tokens；`state` 与最长单个问题合计最多 32K tokens。仅支持文本输入，图片、音频、视频需先转换为文本或结构化字段。

接口返回非流式 JSON；`stream` 请省略或设为 `false`，传入 `true` 会返回参数错误。

## 用量与计费

`usage.input_tokens` 和 `usage.output_tokens` 分别表示输入、输出用量。JEV 输入按 token 收费，当前平台输出免费，具体输入单价和账号折扣以模型广场及实际账单为准。

本例启用了 `include_cost`：`usage.cost` 为费用字符串，`usage.currency` 为 `USD`，`usage.cost_status` 为 `calculated`。未启用时仍返回 token 用量。

完整字段定义见 [System One（JEV）接口参考](/api-reference/endpoint/systemone)。
