# 火山引擎流式语音识别

通过 WebSocket 接口 `/v1/stream_asr` 持续发送 PCM 音频，并实时接收识别结果。

## 可用模型

| 模型 | 说明 |
| --- | --- |
| `volcengine_bigmodel` | 火山引擎大模型流式语音识别 |
| `volcengine_normal` | 火山引擎流式语音识别 |

## 大模型流式语音识别 API

`volcengine_bigmodel` 对接火山引擎的基础双向流式接口 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel`。平台接收 JSON 文本消息，负责与上游交互，并将识别结果转换为下文的服务端事件。

| 项目 | 值 |
| --- | --- |
| 平台模型名 | `volcengine_bigmodel` |
| 平台接口 | `/v1/stream_asr?model=volcengine_bigmodel` |
| 上游模式 | 基础双向流式，持续输入音频并接收转写 |
| 上游 1.0 并发版资源 ID | `volc.bigasr.sauc.concurrent` |

上游资源 ID 和火山鉴权凭据由平台账号配置。调用时使用平台 API Key，音频与会话参数通过本页定义的 JSON 消息发送。

正式环境建连地址如下。

```text
wss://model-api.skyengine.com.cn/v1/stream_asr?model=volcengine_bigmodel
```

测试环境建连地址如下，使用对应环境的平台 API Key。

```text
wss://model-api-test.skyengine.com.cn/v1/stream_asr?model=volcengine_bigmodel
```

## 音频要求

发送的音频必须满足以下要求：

| 项目 | 要求 |
| --- | --- |
| 编码 | PCM signed 16-bit little-endian |
| 采样率 | 16000 Hz |
| 声道 | 单声道 |
| 容器 | 裸 PCM，不包含 WAV 文件头 |

如果源文件不是该格式，可先使用 FFmpeg 转换：

```bash
ffmpeg -i input.mp3 -f s16le -acodec pcm_s16le -ac 1 -ar 16000 input.pcm
```

## Python 示例

安装 WebSocket 客户端：

```bash
pip install websockets
```

以下示例读取 `input.pcm`，按 100 毫秒分片发送，并在音频末尾补充静音以触发完整识别结果：

```python
import asyncio
import base64
import json
import os

import websockets

API_KEY = os.environ["MODELHUB_API_KEY"]
MODEL = "volcengine_normal"
WS_URL = f"wss://model-api.skyengine.com.cn/v1/stream_asr?model={MODEL}"


async def recognize(path: str) -> None:
    headers = {"Authorization": f"Bearer {API_KEY}"}

    async with websockets.connect(WS_URL, additional_headers=headers) as ws:
        with open(path, "rb") as audio_file:
            while chunk := audio_file.read(3200):
                await ws.send(json.dumps({
                    "type": "input_audio_buffer.append",
                    "audio": base64.b64encode(chunk).decode(),
                }))
                await asyncio.sleep(0.1)

        # 1 秒 16 kHz、16-bit、单声道静音
        await ws.send(json.dumps({
            "type": "input_audio_buffer.append",
            "audio": base64.b64encode(bytes(32000)).decode(),
        }))

        completed = []
        while True:
            try:
                message = await asyncio.wait_for(ws.recv(), timeout=3)
            except asyncio.TimeoutError:
                break
            event = json.loads(message)
            if event.get("type") == "error":
                raise RuntimeError(event["error"]["message"])
            if event.get("type") == "conversation.item.input_audio_transcription.delta":
                print("实时结果：", event["transcript"])
            if event.get("type") == "conversation.item.input_audio_transcription.completed":
                completed.append(event["transcript"])

        print("最终结果：", "".join(completed))


asyncio.run(recognize("input.pcm"))
```

将 `MODEL` 改为 `volcengine_bigmodel` 即可调用大模型流式识别。

## 请求格式

ASR 使用 WebSocket 协议，因此建连请求没有 HTTP JSON Body。连接成功后，客户端通过 WebSocket 文本消息发送 JSON Body。

建连地址：

```text
wss://model-api.skyengine.com.cn/v1/stream_asr?model=volcengine_normal
```

建连 Header：

```text
Authorization: Bearer <API-KEY>
```

WebSocket 连接建立后，可以直接发送音频 Body：

```json
{
  "type": "input_audio_buffer.append",
  "audio": "<BASE64_PCM_AUDIO>"
}
```

如果需要设置识别语言，可以先发送会话配置 Body：

```json
{
  "type": "session.config",
  "config": {
    "language": "zh-CN"
  }
}
```

发送了 `session.config` 时，请等待平台返回 `session.ready`，然后再发送音频 Body。不需要设置会话参数时，无需发送 `session.config`，也无需等待 `session.ready`。

音频 Body：

```json
{
  "type": "input_audio_buffer.append",
  "audio": "<BASE64_PCM_AUDIO>"
}
```

## 连接参数

| 参数 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model` | URL Query | 是 | 使用的 ASR 模型名称。 |
| `Authorization` | Header | 是 | `Bearer <API-KEY>`。 |
| `denoise` | URL Query | 否 | 平台降噪实现名称，仅对已注册实现生效，当前仓库未提供可用名称。 |

`model` 选择平台模型，`denoise` 交给平台降噪模块处理。下文的 `config.request` 作为上游识别参数发送。

## 客户端事件

| 公共字段 | JSON 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 事件类型。 |
| `event_id` | string | 否 | 客户端事件标识，`input_audio_buffer.commit` 要求填写。 |
| `trace_id` | string | 否 | 客户端追踪信息。 |

### `session.config`

配置当前识别会话。该事件不是必需步骤；只有需要设置会话参数时才发送。发送后应等待平台返回 `session.ready`，再开始发送音频。

`config` 是可选的 JSON 对象，省略时使用默认配置。对象内的字段如下。

```json
{
  "type": "session.config",
  "config": {
    "language": "zh-CN",
    "enable_itn": true,
    "enable_punc": true,
    "enable_ddc": false
  }
}
```

| `config` 参数 | 类型 | 默认值 | 适用模型 | 说明 |
| --- | --- | --- | --- | --- |
| `request` | object | 未设置 | 两款模型 | 非空对象会整体替换默认上游 `request`，字段按原键和 JSON 类型透传。 |
| `language` | string | 未指定 | 两款模型 | 写入上游 `audio.language`，设置 `request` 时仍会传递。火山文档将大模型指定语种能力限定在 `bigmodel_nostream`，当前基础双向流式接口按上游能力处理。 |
| `enable_itn` | boolean | `true` | `volcengine_bigmodel` | 开启数字、日期等内容的文本规整。 |
| `enable_punc` | boolean | `true` | `volcengine_bigmodel` | 在识别结果中添加标点。 |
| `enable_ddc` | boolean | `false` | `volcengine_bigmodel` | 开启语义顺滑。 |
| `hotwords` | string[] | 未设置 | 两款模型 | 当前实现接受该字段，但未写入上游请求。热词按下文的 `request.corpus.context` 传入。 |

`enable_itn`、`enable_punc` 和 `enable_ddc` 这三个快捷配置仅在 `request` 未设置或为 `{}` 时参与生成大模型默认请求。`volcengine_normal` 使用 `language` 和非空的 `request`。

不发送 `session.config` 时，WebSocket 建连成功后可以直接发送第一条 `input_audio_buffer.append`，平台将使用模型默认配置。

首次 `session.config` 或首条音频消息会确定会话配置，后续配置消息不会修改该会话。`session.ready` 表示平台已接收配置，上游校验失败通过 `error` 事件返回。

### 大模型参数透传

使用 `volcengine_bigmodel` 时，将火山的 `request` 对象放入 `config.request`。平台对该对象保留原有键名、嵌套结构和 JSON 值类型。火山后续新增的 `request` 字段也会沿该路径发送，字段有效性由上游校验。

非空 `config.request` 会整体替换平台生成的默认对象。请显式包含 `model_name: "bigmodel"` 和 `show_utterances: true`，以及需要的识别选项。平台依赖上游分句中的 `definite` 判断最终结果，`show_utterances` 应保持为 `true`。

```json
{
  "type": "session.config",
  "event_id": "event_config_1",
  "trace_id": "client_trace_1",
  "config": {
    "request": {
      "model_name": "bigmodel",
      "enable_itn": true,
      "enable_punc": true,
      "enable_ddc": false,
      "show_utterances": true,
      "result_type": "single",
      "end_window_size": 800,
      "corpus": {
        "context": "{\"hotwords\":[{\"word\":\"ModelHub\"},{\"word\":\"语音识别\"}]}"
      }
    }
  }
}
```

下面列出火山大模型文档中的 `request` 参数。表中的上游默认值适用于该字段未传入时，实际能力取决于账号配置的接口模式和模型版本。基础双向流式、优化双向流式和流式输入分别对应 `bigmodel`、`bigmodel_async` 和 `bigmodel_nostream`。

| `config.request` 参数 | JSON 类型 | 上游默认值或取值 | 用途与条件 |
| --- | --- | --- | --- |
| `model_name` | string | `"bigmodel"` | 必填模型标识。 |
| `enable_itn` | boolean | `true` | 文本规整。 |
| `enable_punc` | boolean | `true` | 标点。 |
| `enable_ddc` | boolean | `false` | 语义顺滑。 |
| `show_utterances` | boolean | 请显式设为 `true` | 平台最终结果所需的分句信息。 |
| `result_type` | string | `"full"` 或 `"single"` | 上游文本范围。 |
| `output_zh_variant` | string | `"traditional"`、`"tw"`、`"hk"` | 繁体输出。 |
| `enable_accelerate_text` | boolean | `false` | 首字加速。 |
| `accelerate_score` | integer | `0`，范围 `0`～`20` | 加速程度。 |
| `vad_segment_duration` | integer | `3000` 毫秒 | 语义切句阈值，设置 `end_window_size` 后失效。 |
| `end_window_size` | integer | `800` 毫秒，最小 `200` | 静音判停。 |
| `force_to_speech_time` | integer | 最小 `1` 毫秒 | 最短判停时长，配合 `end_window_size`。 |
| `sensitive_words_filter` | string | JSON 字符串 | 过滤设置。 |
| `corpus` | object | 未指定 | 语料配置，见下表。 |
| `enable_nonstream` | boolean | 未指定 | 二遍识别，要求优化双向流式。 |
| `enable_speaker_info` | boolean | `false` | 说话人分离，需匹配语种与版本，优化双向流式另需二遍。 |
| `ssd_version` | string | `"200"` | 配合说话人分离。 |
| `enable_auto_lang` | boolean | `false` | 自动语种，要求流式输入。 |
| `show_speech_rate` | boolean | `false` | 语速，要求流式输入或优化双向流式。 |
| `show_volume` | boolean | `false` | 音量，同上。 |
| `enable_lid` | boolean | `false` | 语种检测，同上。 |
| `enable_emotion_detection` | boolean | `false` | 情绪检测，同上。 |
| `enable_gender_detection` | boolean | `false` | 性别检测，同上。 |
| `enable_poi_fc` | boolean | 未指定 | POI 辅助，要求流式输入或开启二遍的优化双向流式。 |
| `enable_music_fc` | boolean | 未指定 | 音乐辅助，同上。 |

当前 `volcengine_bigmodel` 使用基础双向流式接口。表中带模式条件的字段可以透传，其功能生效需要相应的上游接口和账号配置。平台对外转写事件的字段范围见“服务端事件”。参数能力与版本条件可查阅火山官方说明。[大模型流式语音识别 API](https://docs.volcengine.com/docs/doubao-voice/large-model-streaming-automatic-speech-recognition-api-1?lang=zh)

#### 语料与热词参数

| `config.request.corpus` 参数 | JSON 类型 | 用途 |
| --- | --- | --- |
| `boosting_table_name` | string | 热词表名称。 |
| `boosting_table_id` | string | 热词表 ID。 |
| `correct_table_name` | string | 替换词表名称。 |
| `correct_table_id` | string | 替换词表 ID。 |
| `context` | string | 序列化的热词或上下文 JSON。 |

`corpus.context` 的字符串内容可包含以下字段，平台保留字符串本身。

| 字符串内的 JSON 路径 | 类型 | 用途与条件 |
| --- | --- | --- |
| `hotwords` | object[] | 热词列表。 |
| `hotwords[].word` | string | 热词文本。 |
| `context_type` | string | 上下文模式 `"dialog_ctx"`。 |
| `context_data` | object[] | 按新到旧排列的上下文。 |
| `context_data[].text` | string | 文本上下文。 |
| `context_data[].image_url` | string | 图片上下文，要求上游 2.0 能力。 |
| `loc_info.city_name` | string | POI 辅助的城市信息。 |

敏感词设置 `sensitive_words_filter` 同样使用 JSON 字符串，内部字段为 `system_reserved_filter`（boolean）、`filter_with_empty`（string[]）和 `filter_with_signed`（string[]）。

```json
{
  "type": "session.config",
  "config": {
    "request": {
      "model_name": "bigmodel",
      "show_utterances": true,
      "enable_itn": true,
      "enable_punc": true,
      "enable_ddc": false,
      "sensitive_words_filter": "{\"system_reserved_filter\":true,\"filter_with_empty\":[\"示例词一\"],\"filter_with_signed\":[\"示例词二\"]}"
    }
  }
}
```

#### 音频与普通 ASR 的透传规则

大模型上游的 `audio.format`、`audio.rate`、`audio.bits`、`audio.channel` 由平台设置为 `pcm`、`16000`、`16`、`1`。`config.language` 单独映射到 `audio.language`。`config.request` 中的字段全部放入上游 `request`。`config.audio`、`config.user` 等配置表之外的字段会被忽略。

`volcengine_normal` 的非空 `config.request` 也会整体替换默认上游请求。普通 ASR 默认生成 `show_utterances: true`、`result_type: "single"`、`sequence: 1` 和识别 `workflow`。使用自定义对象时，平台仅在缺失时补齐 `reqid`、`sequence`，其余字段需要调用者自行提供。普通 ASR 透传的 `request` 字段按其 `/api/v2/asr` 协议校验。

### `input_audio_buffer.append`

发送一段 Base64 编码的 PCM 音频。建议按固定时长连续发送，不要一次发送完整的长音频。

```json
{
  "type": "input_audio_buffer.append",
  "audio": "<BASE64_PCM_AUDIO>"
}
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定为 `input_audio_buffer.append`。 |
| `audio` | string | 是 | Base64 编码的 PCM 音频字节。 |
| `event_id` | string | 否 | 客户端事件标识。 |
| `trace_id` | string | 否 | 客户端追踪信息，在实现保留关联信息的服务端事件中返回。 |

### `input_audio_buffer.commit`（仅 `volcengine_normal`）

最后一包音频发送完毕后，发送该事件，明确结束当前语音段，无需再补静音。平台会向火山发送协议尾包，并等待最终识别结果。

```json
{
  "type": "input_audio_buffer.commit",
  "event_id": "event_xxx"
}
```

`event_id` 必填，长度为 1～128 字节，每一轮使用新的 ID。平台会忽略近期已经接受的同 ID commit 重发。

发送后请等待 `conversation.item.input_audio_transcription.completed`，再开始发送下一轮音频；对外 WebSocket 连接可以继续复用。等待期间发送下一轮音频、提交另一个 commit，或对空音频缓冲区提交 commit，会收到 `invalid_request_error`，其中 `error.event_id` 指向触发错误的客户端事件。

完成事件仍使用现有的 `input_audio_buffer.speech_stopped` 和 `conversation.item.input_audio_transcription.completed`，不额外发送 commit 确认事件。只有静音的音频也可能返回空的最终文本。等待最终结果超过 5 秒，或上游断连、重连失败时，会返回服务端错误并结束连接。

`volcengine_bigmodel` 不支持该事件，会返回 `invalid_request_error`。不发送 commit 的调用方式继续使用原来的 VAD 自动判停。

## 服务端事件

所有事件通过 WebSocket 文本消息返回，每条消息是一个 JSON 对象。

| 事件 | 说明 |
| --- | --- |
| `session.ready` | 会话配置完成，可以开始发送音频。 |
| `conversation.item.created` | 创建了一段新的语音识别内容。 |
| `input_audio_buffer.speech_started` | 检测到语音开始。 |
| `conversation.item.input_audio_transcription.delta` | 当前语音段的实时累计识别文本。 |
| `input_audio_buffer.speech_stopped` | 检测到语音结束。 |
| `conversation.item.input_audio_transcription.completed` | 当前语音段的最终识别文本；一次连接可能返回多条。 |
| `error` | 请求或识别失败。 |

| 公共字段 | JSON 类型 | 说明 |
| --- | --- | --- |
| `event_id` | string | 服务端生成的事件标识。 |
| `type` | string | 事件类型。 |
| `trace_id` | string | 可选的关联追踪信息，存在时返回。`session.ready` 会回传配置消息中的 `trace_id`。 |

以下示例中的 ID 和时间值用于说明字段格式。一次语音段的常见事件顺序为 `conversation.item.created`、`input_audio_buffer.speech_started`、多条 `delta`、`input_audio_buffer.speech_stopped`、`completed`。同一语音段使用相同的 `item_id`。

### `session.ready`

发送 `session.config` 后返回。

```json
{
  "event_id": "event_ready_1",
  "type": "session.ready",
  "trace_id": "client_trace_1"
}
```

### `conversation.item.created`

创建当前语音段的会话项。

```json
{
  "event_id": "event_created_1",
  "type": "conversation.item.created",
  "previous_item_id": null,
  "item": {
    "id": "item_1",
    "object": "realtime.item",
    "status": "completed",
    "type": "message",
    "role": "user",
    "content": [
      {
        "type": "input_audio"
      }
    ]
  }
}
```

`item.id` 是后续转写事件关联的 `item_id`。`item.status` 是平台当前生成会话项时填写的值，语音段最终转写完成以 `conversation.item.input_audio_transcription.completed` 为准。

### `input_audio_buffer.speech_started`

```json
{
  "event_id": "event_started_1",
  "type": "input_audio_buffer.speech_started",
  "item_id": "item_1",
  "audio_start_ms": 120
}
```

`audio_start_ms` 是平台按会话时间轴估算的开始位置，单位为毫秒，零值时该字段省略。

### `conversation.item.input_audio_transcription.delta`

```json
{
  "event_id": "event_delta_1",
  "type": "conversation.item.input_audio_transcription.delta",
  "item_id": "item_1",
  "content_index": 0,
  "transcript": "你好，这是语音识别"
}
```

`content_index` 当前为 `0`。`transcript` 是本次上游结果对应的当前文本，默认请求下会随识别推进更新，客户端应更新同一 `item_id` 的展示文本。使用 `config.request.result_type` 时，文本范围同时受上游的 `full` / `single` 设置影响。

### `input_audio_buffer.speech_stopped`

```json
{
  "event_id": "event_stopped_1",
  "type": "input_audio_buffer.speech_stopped",
  "item_id": "item_1",
  "audio_end_ms": 5100
}
```

`audio_end_ms` 是平台会话时间轴上的结束位置，单位为毫秒，零值时该字段省略。

### `conversation.item.input_audio_transcription.completed`

```json
{
  "event_id": "event_completed_1",
  "type": "conversation.item.input_audio_transcription.completed",
  "item_id": "item_1",
  "content_index": 0,
  "transcript": "你好，这是语音识别测试。",
  "audio_duration": 5
}
```

| 字段 | JSON 类型 | 说明 |
| --- | --- | --- |
| `item_id` | string | 当前语音段标识。 |
| `content_index` | integer | 当前为 `0`。 |
| `transcript` | string | 最终识别文本。 |
| `audio_duration` | integer | 音频时长，单位为秒，零值时省略。大模型按本次连接累计收到的 PCM 字节数计算并向下取整，包含发送的静音。普通 ASR 优先使用实现提供的音频时长。 |

客户端收到该事件后可继续在当前 WebSocket 连接中发送下一段音频。大模型使用 VAD 自动判停，音频发送结束后继续按分片节奏补充静音，并等待最终事件。

### `error`

客户端事件或参数错误使用 `invalid_request_error`。下面以向大模型提交 `input_audio_buffer.commit` 为例，`error.event_id` 关联触发错误的客户端事件。

```json
{
  "event_id": "event_error_1",
  "type": "error",
  "error": {
    "type": "invalid_request_error",
    "code": null,
    "message": "input_audio_buffer.commit is only supported for volcengine_normal",
    "param": null,
    "event_id": "event_commit_1"
  }
}
```

上游连接或识别失败使用 `server_error`。部分错误响应会省略值为空的可选字段。

```json
{
  "event_id": "event_error_2",
  "type": "error",
  "error": {
    "type": "server_error",
    "message": "connect asr model failed: websocket: bad handshake"
  }
}
```

| `error` 字段 | JSON 类型 | 说明 |
| --- | --- | --- |
| `type` | string | `invalid_request_error` 或 `server_error`。 |
| `message` | string | 实际错误信息。 |
| `code` | 任意 JSON 值或 null | 可选的错误码，当前 Provider 通常返回 null。 |
| `param` | 任意 JSON 值或 null | 可选的参数定位信息。 |
| `event_id` | string 或 null | 可选的客户端事件标识。 |

### 透传参数与返回字段的对应关系

平台当前对外返回识别文本、语音段标识、平台会话时间和音频时长。上游 `utterances`、`words`、逐词时间戳、说话人编号以及语速、音量、语种、情绪、性别等附加信息尚未映射到对外事件。设置对应上游参数时，请按上面的平台响应字段读取结果。

火山参数及适用模式可查阅官方文档。[大模型流式语音识别 API](https://docs.volcengine.com/docs/doubao-voice/large-model-streaming-automatic-speech-recognition-api-1?lang=zh)
