title: 'Lyria 3 音乐生成'
---

`POST /v1/interactions`

使用 Lyria 3 Clip 或 Pro 从文字或图片生成音乐。请求体中的 `model` 使用模型广场显示的名称。Clip 生成短片段，Pro 适用于完整歌曲。

平台支持 Google Cloud 路径 `POST /v1/projects/{project}/locations/global/interactions`。调用时使用平台域名和 API Key，实际 Google Cloud 项目由平台的模型账号映射决定。

| 字段 | 说明 |
| --- | --- |
| `input` | 支持文本字符串和 Google Interactions 的结构化输入。可以在 `user_input.content` 中提供文本和图片。 |
| `store` | 使用 `false`，省略时平台会补上。Lyria 3 使用无状态调用。 |
| `stream` | 默认返回 JSON。传 `true` 时透传上游 SSE 事件。 |
| `Api-Revision` | 可选请求头。省略时使用 `2026-05-20`。 |

## 请求示例

在本地终端配置 `TOKENOPS_API_KEY` 环境变量后运行。

```bash cURL
curl --request POST \
  --url https://model-api.skyengine.com.cn/v1/interactions \
  --header 'Api-Revision: 2026-05-20' \
  --header "Authorization: Bearer ${TOKENOPS_API_KEY}" \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "lyria-3-clip-preview",
    "store": false,
    "input": "Create a gentle instrumental clip with acoustic guitar and soft piano."
  }'
```

## 响应格式

### 同步 JSON

`stream` 省略或为 `false` 时，成功响应的 `Content-Type` 为 `application/json`。平台返回 Google Interactions 响应，以下示例中的音频数据为占位符。

```json
{
  "id": "interaction_example",
  "status": "completed",
  "object": "interaction",
  "model": "lyria-3-clip-preview",
  "steps": [
    {
      "type": "model_output",
      "content": [
        {
          "type": "audio",
          "mime_type": "audio/mpeg",
          "data": "BASE64_MP3_AUDIO"
        }
      ]
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 交互 ID。 |
| `status` | 交互状态。生成完成时为 `completed`。 |
| `steps[]` | 交互步骤。遍历 `type` 为 `model_output` 的步骤，查找 `content[]` 中 `type` 为 `audio` 的条目。步骤中也可能包含歌词或描述等文本内容。 |
| `steps[].content[].data` | 音频的 Base64 数据。字段存在时，解码后可保存为 MP3。若上游返回 `uri`，音频位于该地址。 |
| `steps[].content[].mime_type` | 可选的音频 MIME 类型，例如 `audio/mpeg`。 |

### 流式 SSE

`stream: true` 时，平台透传 `text/event-stream`。事件之间以空行分隔。解析 `data:` 后的 JSON，查找 `event_type` 为 `step.delta` 且 `delta.type` 为 `audio` 的事件，再将 `delta.data` 做 Base64 解码。`index` 标识所属步骤。实际事件还可能包含可选的 `event_id`，`delta` 也可能返回 `uri` 而省略 `data`。

```text
event: step.delta
data: {"event_type":"step.delta","index":0,"delta":{"type":"audio","mime_type":"audio/mpeg","data":"BASE64_MP3_CHUNK"}}

event: interaction.completed
data: {"event_type":"interaction.completed","interaction":{"id":"interaction_example","status":"completed"}}

event: done
data: [DONE]
```

`interaction.completed` 表示交互结束，音频应从先前的音频事件读取。若收到 `data: [DONE]`，将其作为结束标记处理。
